# Oblivious Routing on the Hypercube

Study of randomness requirements and time–randomness tradeoffs in oblivious
permutation routing on the hypercube, conducted under Prof. Shreyas Pai.

The report studies:
- An Ω(n) randomness lower bound for O(n) expected routing time
- An existential O(n)-randomness construction via the probabilistic method
- The time–randomness–reliability tradeoff (T, R, Q)
